### **项目需求概览**

*   **主控制器**：STM32 微控制器，工作电压 3.3V。
*   **主电源**：USB 5V。
*   **备用电源**：单节 3.7V 锂离子电池（电压范围 3.0V - 4.2V），带有保护板。
*   **核心功能**：
    1.  当 USB 插入时，系统由 USB 供电，并同时为锂电池充电。
    2.  当 USB 拔出时，系统自动、无缝地切换到由锂电池供电。
    3.  无论使用何种电源，STM32 始终获得稳定的 3.3V 供电。

### **详细技术设计指导**

#### **1. 充电管理模块 (Charger)**

*   **芯片选型**：**UMW TP4054**（或同类产品 TP4056）。
*   **电路设计**：
    *   **VCC (Pin 4)**：连接到 USB 的 5V VBUS。**必须**在 VCC 和 GND 之间放置一个 **10µF** 的陶瓷电容 (X7R/X5R) 和一个 **0.1µF** 的陶瓷电容。这两个电容要尽可能靠近芯片引脚，用于输入电压滤波和退耦。
    *   **GND (Pin 2)**：连接到系统地。
    *   **BAT (Pin 3)**：连接到电池保护板的 P+ 端。同时，在 BAT 和 GND 之间放置一个 **10µF** 的陶瓷电容，以稳定充电过程。
    *   **PROG (Pin 5)**：通过一个电阻（R_PROG）接地，用于设定充电电流。
        *   **充电电流计算**：`I_CHG(mA) = 1000 / R_PROG(kΩ)`。
        *   **推荐设置**：考虑到 USB 2.0 的 500mA 限制以及 STM32 的功耗，建议设定充电电流为 **300mA ~ 400mA**。例如，要设定 400mA，`R_PROG = 1000 / 400 = 2.5kΩ`。
    *   **CHRG (Pin 1)**：充电状态指示引脚（漏极开路）。通过一个上拉电阻（例如 10kΩ）拉到 3.3V，然后连接一个 LED 到地。充电时，引脚拉低，LED 亮；充满时，引脚高阻，LED 灭。

#### **2. 电源路径管理模块 (Power Path Multiplexer)**

这是实现无缝切换的关键，我们使用两个 P-MOSFET 来构建一个“理想二极管”式的切换电路。

*   **元件选型**：
    *   **Q1, Q2**：两个 P沟道 MOSFET。选择时注意：
        *   **低 Vgs(th)**：开启阈值电压要低，确保电池电压能可靠地开启它（例如 -1.5V 以下）。
        *   **低 Rds(on)**：导通电阻要低（例如 < 50mΩ），以减小电池供电时的压降和功耗。
        *   **SOT-23** 封装的 P-MOSFET 很常见，如 **AO3401A**。
    *   **R1, R2**：两个下拉电阻，推荐值 **100kΩ**。
*   **电路连接**：
    *   USB 5V VBUS 连接到 **Q2 的源极(S)**。
    *   电池保护板的 P+ 端连接到 **Q1 的源极(S)**。
    *   Q1 和 Q2 的**漏极(D)** 连接在一起，这个节点我们称之为 **V_SYS**。
    *   **Q1 的栅极(G)** 通过电阻 **R1** 连接到地，同时连接到 **Q2 的源极(S)** (即USB 5V)。
    *   **Q2 的栅极(G)** 通过电阻 **R2** 连接到地。
*   **工作原理简述**：
    *   **USB 接入**：5V 电压通过 R1 将 Q1 的栅极拉高，使其截止；同时 Q2 的栅极被 R2 拉低，使其导通。`V_SYS` 由 USB 5V 供电。
    *   **USB 拔出**：Q1 的栅极通过 R1 被拉到地，使其导通；Q2 因源极无电压而截止。`V_SYS` 由电池供电。

#### **3. 升降压稳压模块 (Buck-Boost Converter)**

这是为 STM32 提供稳定 3.3V 的核心。

*   **芯片选型**：**TI TPS63021** (固定 3.3V 输出版本)。
*   **电路设计**（参考 TPS63021 数据手册典型应用）：
    *   **VIN (Pin 10, 11)**：连接到上一级的 **V_SYS** 节点。
    *   **VINA (Pin 1)**：也连接到 **V_SYS**。在 VINA 和 GND 之间放置一个 **0.1µF** 的陶瓷电容。
    *   **GND (Pin 2)** 和 **PGND (Exposed Pad, Pin 15-18)**：这是关键。GND 是控制地，PGND 是功率地。在 PCB 上，它们应该在**一个单点**连接，这个点应靠近芯片的 GND 引脚。
    *   **L1, L2 (Pin 8,9 and 6,7)**：连接一个 **1.5µH** 的功率电感。电感必须具有低 DCR 和足够的饱和电流（至少 3A 以上）。
    *   **VOUT (Pin 4, 5)**：这是最终的 3.3V 输出。
    *   **FB (Pin 3)**：由于使用的是固定 3.3V 的 TPS63021，此引脚直接连接到 **VOUT**。
    *   **EN (Pin 12)**：连接到 `V_SYS` 或一个 GPIO，以控制芯片使能。若希望系统始终开启，可直接上拉到 `V_SYS`。
    *   **PS/SYNC (Pin 13)**：决定工作模式。
        *   **接地**：启用轻载省电模式（推荐，可延长电池续航）。
        *   **接高电平 (V_SYS)**：强制 PWM 模式（效率略低，但纹波更小）。
    *   **输入/输出电容**：
        *   **输入端 (V_SYS)**：放置 **2x10µF** (或更大) 陶瓷电容。
        *   **输出端 (VOUT)**：放置 **3x22µF** (或更大) 陶瓷电容，以获得最佳的负载瞬态响应。

#### **4. PCB 布局特别指导**

电源电路的性能 90% 取决于 PCB 布局。请严格遵守以下规则：

1.  **大电流环路最小化**：
    *   **输入环路**：从 V_SYS，经过 TPS63021 的输入电容、电感、内部开关，再回到 PGND。这个环路的面积必须尽可能小。
    *   **输出环路**：从电感，经过 TPS63021 的内部开关、输出电容，再回到 PGND。这个环路的面积也必须尽可能小。
2.  **元件放置**：
    *   将 **TPS63021、电感、输入/输出电容** 紧密地放置在一起。
    *   所有退耦电容（如 TP4054 的输入/输出电容，TPS63021 的 VINA 电容）必须紧贴对应芯片的引脚放置。
3.  **接地处理 (至关重要)**：
    *   使用**大面积的接地层 (Ground Plane)**，最好是多层板的中间层。
    *   **TPS63021 的散热焊盘 (Exposed Pad)** 必须通过多个**热过孔 (Thermal Vias)** 连接到接地层。这既是功率地 (PGND) 的连接，也是主要的散热途径。
    *   **GND 和 PGND 单点接地**：将所有控制部分的接地（如电阻分压器、EN/PS 引脚的下拉电阻等）连接到芯片的 GND 引脚，形成一个“星形”接地的控制地网络。然后，在芯片下方，通过一个短而粗的走线将 GND 引脚连接到 PGND（即散热焊盘）。
4.  **走线宽度**：
    *   所有承载大电流的路径（VBUS, V_SYS, VOUT, BAT+, GND）都应使用**短而粗**的走线。可以使用在线 PCB 走线宽度计算器来确定具体宽度。

### **调试与验证步骤**

1.  **分步焊接与测试**：不要一次性焊完所有元件。
    *   先焊接 **TP4054 及其外围**，用 USB 供电，测试能否正常为电池充电，CHRG 指示灯是否正常。
    *   再焊接 **电源路径管理模块 (P-MOSFETs)**，测试插拔 USB 时，`V_SYS` 节点的电压是否能在 5V 和电池电压之间正确切换。
    *   最后焊接 **TPS63021 及其外围**，验证 `V_SYS` 在 3.0V 到 5V 变化时，VOUT 是否始终稳定在 3.3V。
2.  **负载测试**：在 3.3V 输出端连接您的 STM32 系统（或等效的电子负载），测试在不同工作模式（如全速运行、低功耗睡眠）下，3.3V 电压的稳定性。
3.  **切换测试**：在系统运行时，反复快速插拔 USB，用示波器观察 3.3V 输出电压，确保没有明显的掉电或尖峰，切换平滑。
