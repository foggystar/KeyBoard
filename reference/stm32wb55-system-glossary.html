STM32WB55 的五个系统模块

围绕 CPU1 应用核与 CPU2 无线核理解 RCC、HSEM、IPCC、RTC 和 RNG。

模块全称核心职责直觉类比
RCCReset and Clock Control选择、分频和分配系统及外设时钟，并控制复位配电室与节拍器
HSEMHardware Semaphore让 CPU1 和 CPU2 对共享资源加硬件锁会议室门锁
IPCCInter-Processor Communication Controller在两个 CPU 之间发送通道通知和中断双向门铃
RTCReal-Time Clock低速计时、日历、闹钟及定时唤醒持续运行的闹钟
RNGRandom Number Generator产生硬件随机数，供地址和安全协议使用硬件骰子
一句话：RCC 让各模块“有节拍”，HSEM 防止两个核“同时抢”，IPCC 告诉另一个核“有消息”，RTC 决定“何时做”，RNG 提供“不可预测的数”。
