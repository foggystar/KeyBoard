STM32WB55 BLE HID 键盘速查

目标：把按键状态变成标准 HOGP Input Report，让 Windows、Android、iOS 将板子识别为键盘。

标准服务

服务UUID作用
Human Interface Device Service0x1812Report Map、Input Report、Control Point 等 HID 数据
Battery Service0x180F电量百分比；HOGP HID Device 的标准组成
Device Information Service0x180A厂商、型号、PnP ID 等设备信息

8 字节键盘 Input Report

字节含义例子
0Ctrl/Shift/Alt/GUI 修饰键位图0x02 = Left Shift
1保留，固定为 00x00
2..7最多 6 个同时按下的键盘 Usage ID0x04 = A 键
按下 A: 00 00 04 00 00 00 00 00
释放全部: 00 00 00 00 00 00 00 00
按下 Shift+A: 02 00 04 00 00 00 00 00
必须发释放报告。只发按下、不发全零报告，主机会认为按键一直按住，可能产生连续输入。

最小键盘 Report Map（无 LED Output Report）

static const uint8_t keyboard_report_map[] = {
  0x05, 0x01,       /* Usage Page (Generic Desktop) */
  0x09, 0x06,       /* Usage (Keyboard) */
  0xA1, 0x01,       /* Collection (Application) */
  0x05, 0x07,       /* Usage Page (Keyboard/Keypad) */
  0x19, 0xE0, 0x29, 0xE7,
  0x15, 0x00, 0x25, 0x01,
  0x75, 0x01, 0x95, 0x08,
  0x81, 0x02,       /* 8 modifier bits */
  0x95, 0x01, 0x75, 0x08,
  0x81, 0x01,       /* reserved byte */
  0x95, 0x06, 0x75, 0x08,
  0x15, 0x00, 0x25, 0x65,
  0x05, 0x07, 0x19, 0x00, 0x29, 0x65,
  0x81, 0x00,       /* six key usages */
  0xC0
};

STM32WB 发送 API

uint8_t report[8] = {0};

report[2] = 0x04;  /* press A */
HIDS_Update_Char(REPORT_CHAR_UUID, 0, 0, sizeof report, report);

memset(report, 0, sizeof report);  /* release */
HIDS_Update_Char(REPORT_CHAR_UUID, 0, 0, sizeof report, report);

只有主机已配对并为 Input Report 开启 Notification 后才发送。不要在中断里直接连续调用 BLE ACI；由按键扫描代码投递任务，再让 STM32 sequencer 在主循环上下文发送。

第一次主机测试

  1. 手机/电脑“忘记”旧的 P2P 设备，避免 GATT/HID 描述符缓存。
  2. 从操作系统的蓝牙设置配对，不要只用 nRF Connect 建立普通 GATT 连接。
  3. 打开文本输入框；确认主机已启用 Input Report Notification。
  4. 触发一次按下报告和一次释放报告；期望只出现一个 a。
