RTC 备份域：三层链路与两层写保护

症状：RTC_EnterInitMode() 超时，INITF 不置位。

三层链路

PWR_CR1.DBP = 1
  │  开放备份域写权限
  ▼
RCC_BDCR.RTCSEL = HSE/32，RTCEN = 1
  │  选择并打开 RTC 时钟
  ▼
RTC_ISR.INIT = 1  ──硬件确认──▶  RTC_ISR.INITF = 1

两层写保护

保护层控制位置如何解锁
备份域外层保护PWR_CR1.DBPHAL_PWR_EnableBkUpAccess()
RTC 内层保护RTC_WPR__HAL_RTC_WRITEPROTECTION_DISABLE()
只解开 RTC_WPR 不够。如果 DBP=0，整个备份域仍禁止写入。

本次错误链

  1. 系统复位后，备份域重新受保护，但 RTCSEL 仍可能保留 HSE/32。
  2. 生成代码发现时钟源无需改变，因此没有再次调用 HAL_PWR_EnableBkUpAccess()。
  3. 软件尝试设置 RTC_ISR.INIT，写入没有生效。
  4. 硬件当然不会返回 INITF=1。
  5. HAL 等到超时，返回 HAL_ERROR，最终进入 Error_Handler()。

保留修复

/* USER CODE BEGIN RTC_MspInit 0 */
HAL_PWR_EnableBkUpAccess();
/* USER CODE END RTC_MspInit 0 */
