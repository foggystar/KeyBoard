STM32WB55 BLE Bring-up

自制板、无 LSE、先验证广播与连接。

CubeMX 必需模块

模块设置
RCCHSE = Crystal/Ceramic Resonator；LSE = Disable
HSEMActivate
IPCCActivate；开启 C1 RX occupied 与 C1 TX free 中断
RTCActivate Clock Source；WakeUp = Internal；开启 RTC_WKUP 中断
RNGActivate
RFRF1 = Activate
STM32_WPANBLE；Server Profile；Custom P2P Server = Enabled

无 LSE 时钟

  • RTC source = HSE/32。
  • RF wake-up source = HSE/1024。
  • CFG_LPM_SUPPORTED = 0，首次测试不要进入 STOP/STOP2。
  • 生成后确认 CFG_BLE_LS_SOURCE 使用 CLK_HSE_1024。
  • 若没有完整 SMPS 电感网络，保持 CFG_USE_SMPS = 0。

main.c 结构

HAL_Init();
MX_APPE_Config();
SystemClock_Config();
PeriphCommonClock_Config();
MX_IPCC_Init();
MX_GPIO_Init();
MX_RTC_Init();
MX_RNG_Init();
MX_RF_Init();
MX_APPE_Init();

while (1) {
  MX_APPE_Process();
}

三个成功点

  1. SHCI_C2_BLE_Init() 返回 SHCI_Success。
  2. aci_gap_set_discoverable() 返回 BLE_STATUS_SUCCESS。
  3. 手机扫描到 P2PSRV1，能够连接并触发连接完成事件。
更完整步骤见 最小 BLE 冒烟测试课程。
